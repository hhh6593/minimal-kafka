# D2 Survivors 오프라인 안드로이드 래퍼

[D2 Survivors](https://d2survivors.lol/)(framara의 비공식 Diablo II 팬게임)를
인터넷 없이 안드로이드에서 실행하기 위한 **개인용** WebView 래퍼입니다.
게임 코드나 Diablo II 에셋은 이 저장소에 포함하지 않습니다. `build.sh`가 빌드할 때
사이트를 내려받아 APK 안에만 넣습니다. 만든 APK는 재배포하지 마세요.

## 동작 방식

- 앱이 `127.0.0.1:47811`에 작은 HTTP 서버(`LocalServer.java`)를 띄워 APK에 내장된
  사이트 파일을 제공합니다. localhost는 보안 컨텍스트라서 사이트의 서비스워커와 OPFS
  저장소가 그대로 동작합니다. 포트를 고정해 두었기 때문에 추출된 파일과 세이브가 실행할
  때마다 유지됩니다.
- 게임 에셋(`/d2/`)은 두 가지 방법으로 얻습니다.
  - **서버 파일 + 저장 (`GameFileCache.java`)**: 온라인에서 플레이하면 로컬 서버가 사이트에서
    받은 게임 파일을 앱 저장소에 남깁니다. 오프라인이면 저장해 둔 파일로 플레이합니다. 브라우저
    캐시처럼 게임이 요청한 파일만 하나씩 저장하고, 미리 받아 두지는 않습니다. 그래서 온라인에서
    본 막·직업만 오프라인에서 완전하게 나옵니다.
  - **내 D2 파일**: Diablo II `.mpq`가 든 폴더를 고르면 게임이 OPFS로 추출합니다. 추출한 파일이
    있으면 서비스워커가 서버 파일보다 우선해서 씁니다.
- 사이트는 서버 파일 모드를 곧 종료한다고 안내하고 있습니다. 종료된 뒤에는 새 파일을 받을 수
  없지만, 이미 저장한 파일은 계속 씁니다. 앱 내 업데이트는 서버 파일 모드가 없는 새 버전을
  적용하지 않습니다.
- `tools/patch_offline.py`(빌드 시)와 `Updater.java`(앱 내 업데이트 시)가 같은 패치를 적용합니다:
  1. 터치 전용 기기에서 내 파일 모드를 막는 게이트를 해제합니다.
  2. `showDirectoryPicker`를 쓰지 않게 합니다. WebView에는 이 함수가 있지만 호출하면 항상
     거부되고, 게임은 이를 "취소"로 받아들여 버튼이 무반응이 됩니다.
  3. `webkitdirectory` 대신 다중 파일 선택을 씁니다. Android WebView에는 폴더 선택기가 없습니다.
  4. Cloudflare 분석 비콘을 제거합니다.
- **앱 내 업데이트**: 앱을 켤 때 온라인이면 `build.json`으로 새 게임 버전이 있는지 확인합니다.
  있으면 앱 저장소에 받아 패치해 두고 다음 실행 때 적용합니다. 게임이 업데이트돼도 APK를
  다시 설치할 필요가 없습니다. 패치가 더 이상 맞지 않거나 다운로드에 실패하면 기존 버전을 그대로 씁니다.
- **모바일 조작**: 화면을 가로로 고정합니다(양방향 회전). 길게 누를 때 뜨는 텍스트 선택·진동·
  오버스크롤 효과를 끕니다. 로컬 서버가 모든 페이지에 `/__app/mobile.css`를 넣어, 낮은 가로
  화면에서도 setup 화면의 버튼이 항상 보이게 하고 오프라인에서 쓸 수 없는 링크를 숨깁니다.
- **뒤로가기**: 게임 화면에서는 Esc처럼 게임 메뉴를 엽니다. 1.5초 안에 두 번 누르면 종료합니다.
- `chrome://inspect`로 WebView 디버깅을 할 수 있습니다.

## 사용법

1. APK를 설치합니다("출처를 알 수 없는 앱" 허용 필요).
2. 처음 실행하면 설정 화면이 나옵니다.
   - **HOSTED FILES**: 온라인에서 플레이하면서 파일을 저장합니다. 오프라인으로 쓰고 싶은 막과
     직업은 온라인에서 한 번 플레이해 두세요.
   - **USE MY OWN FILES…**: Diablo II(클래식, 1.14) `.mpq`가 든 폴더(예: `내장 저장공간/Download/diablo2`)를
     고르면, 앱이 하위 폴더까지 `.mpq`를 찾아 추출을 시작합니다. 필수: `d2data.mpq`,
     `d2char.mpq`, `d2sfx.mpq`, `d2exp.mpq`, `patch_d2.mpq`. 선택: `d2music.mpq`,
     `d2xmusic.mpq`, `d2speech.mpq`, `d2xtalk.mpq`.
3. 모드는 게임 안의 Options → GAME OPTIONS → GAME FILES에서 바꿀 수 있습니다.

앱을 삭제하면 저장한 게임 파일, 추출한 파일, 세이브도 함께 지워집니다(앱 데이터에 저장됨).

## 빌드

```sh
sdkmanager "platforms;android-35" "build-tools;35.0.0"
ANDROID_HOME=/path/to/sdk ./build.sh        # 미러 → 패치 → APK
```

서명 키는 `keystore/d2survivors-offline.jks`에 있습니다. 없으면 새로 만듭니다.
같은 키로 서명해야 데이터를 유지한 채 업데이트 설치가 되니 키를 보관해 두세요.
