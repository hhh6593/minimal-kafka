# 바람 서바이버 (개인용 안드로이드 게임)

옛날 바람의나라 그림으로 만든 뱀서(서바이버)류 게임입니다. 혼자 폰에서 하려고 만든 **개인용**이며,
`d2survivors-android`와 같은 구조(APK 안의 작은 로컬 서버 + WebView)를 씁니다.

게임 그림과 소리는 저장소에 넣지 않습니다. 원작 저작권은 넥슨에 있습니다. `build.sh`가 빌드할 때
내려받아 둔 이미지를 변환해 APK 안에만 넣습니다. 만든 APK는 다른 사람에게 배포하지 마세요.

## 게임 구성

- **직업**: 전사, 도적, 주술사, 도사. 기술 이름은 원작 마법을 따릅니다.
  - 전사: 기본 공격(이중공격 → 후면 공격 → 삼중공격 → 측면 공격 …), 백호참, 동귀어진, 백호령
  - 도적: 비영승보, 뇌진주, 투명, 흡성대법, 분신
  - 주술사: 화염주(→ 화영열주 → 화열참주 …), 화염주첨(상하좌우), 백열주, 마비, 저주
  - 도사: 자무주, 지진, 차폐, 소혼강신(불여우·맹수 소환), 금강불체. 한 판에 한 번 스스로 부활
  - 공통: 기원(누리의 기원 → 대지의 기원 → … → 태양의 기원)
- **필살기**: 마력이 가득 차면 오른쪽 아래 버튼으로 씁니다. 건곤대나이(체력 30% 소모), 필살검무,
  헬파이어(보호막), 백호의희원(완전 회복 + 금강불체).
- **사냥터**: 왕초보사냥터 → 쥐굴 → 뱀굴 → 사슴굴 → 돼지굴 → 곰·호랑이굴 → 여우굴 → 흉가 →
  도깨비굴 → 산적굴 → 일본 → 바닷속 → 환상의 섬 → 환상의 섬 화산. 월드맵에서 고르며, 보스
  (서생원, 왕구렁이, 광록지수, 홍돼지, 진웅, 구미호 …)를 쓰러뜨리면 다음 사냥터가 열립니다.
  8:00에 보스, 3:00과 5:30에 우두머리가 나옵니다.
- **움직임**: 몬스터는 원작처럼 48픽셀 칸 위를 상하좌우 한 칸씩 움직이고, 한 칸에 하나만 서며,
  주인공의 바로 옆 칸에서 공격합니다. 주인공도 상하좌우로만 움직이지만 칸에 묶이지 않고 몬스터를
  통과할 수 있습니다. 마법은 날아가지 않고 대상 위에서 바로 터지며, 이펙트는 원래 크기로 그립니다.
  주술사·도사의 마법은 최대 8칸 떨어진 몬스터까지 닿습니다. 경험치는 잡는 즉시 들어옵니다.
- **파티**: 레벨 3·9·15에 다른 직업 동료가 차례로 들어옵니다.
  도사는 체력이 줄면 기원으로 회복하고, 보호를 걸고, 몰린 적에게 저주를 겁니다. 주술사는 화염주와
  마비, 전사는 근접 공격과 백호참, 도적은 비영승보로 돕습니다. 동료는 마법 이름을 외치고(말풍선),
  채팅에 초록색 파티 대화로 나오며, 다치지 않습니다.
- 죽으면 유령이 됩니다. 아래쪽 메시지 창에 원작처럼 시스템 메시지가 뜹니다.
- 몬스터 그림은 정면 한 장씩이라, 걷기는 코드로 표현합니다(들썩임, 좌우 반전, 맞으면 번쩍임).
  마법 이펙트는 GIF의 프레임과 시간을 그대로 쓰고, 검은 배경은 원작처럼 가산 합성으로 지웁니다.

## 성장 구조 (D2 Survivors 기준)

공개된 D2 Survivors 위키의 규칙을 바람의나라에 맞게 옮겼습니다.

- **시작**: 마법 없이 무기 기본 공격만 들고 시작합니다(마법이 1.5초 동안 안 나갈 때만 휘두름).
  첫 카드는 그 직업의 1단계 마법과 기원입니다.
- **마법 단계**: 마법은 캐릭터 레벨 1·6·12·18에 열리고, 마법 레벨은 (캐릭터 레벨 − 열리는 레벨 + 1)을
  넘지 못합니다. 범위 공격(동귀어진, 지진, 화염주첨, 마비 등)은 12레벨부터 나옵니다.
- **카드**: 레벨업마다 3장. 다시 뽑기·넘기기·빼기를 한 판에 2번씩 쓸 수 있습니다. 마법 6칸, 능력 6칸,
  마법은 8단, 능력은 5단까지.
- **조합(각성)**: 마법 8단 + 짝 능력 + 필요 레벨이면 다음 보물 상자에서 각성합니다.
  이중공격+힘 → 어검술, 백호참+체력 단련 → 포효검황, 비영승보+민첩 → 백호검무, 뇌진주+지력 → 쇄혼비무,
  화염주+지력 → 삼매진화, 백열주+공력 → 지폭지술, 자무주+공력 → 노도성황, 지진+체력 단련 → 파력무참.
- **경험치**: 다음 레벨까지 5(1레벨) · 83(10레벨) · 297(25레벨).
- **몬스터**: 최소 수가 사냥터 깊이에 따라 8~80마리로 시작해 5:00에 80~125마리가 되고, 1:00부터 초당
  1마리, 3:00부터 2마리씩 더 나옵니다. 1:30·3:00·4:30에 챔피언 무리(체력 8배), 2:15·4:45에 우두머리와
  부하(체력 12배), 6:00에 보스. 보스가 나오면 필드가 25마리로 줄고, 1:30 뒤부터 보스가 약해져 2:50이면
  반드시 쓰러집니다. 보스를 잡으면 필드의 몬스터가 모두 쓰러집니다.
- **장비**: 일반 몬스터는 3분에 한 번까지, 챔피언 33%, 우두머리 50%, 보스는 2개를 떨어뜨립니다.
  밟으면 주워서 가방에 들어가고(죽어도 유지), **메뉴 → 장비**에서 골라 입습니다.
- **파티**: 레벨 3·9·15에 다른 직업 동료가 차례로 들어오고, 캐릭터 레벨에 맞춰 강해집니다.
- 피해 숫자는 원작 클라이언트와 D2 Survivors 모두 띄우지 않아 기본으로 꺼 두었습니다(메뉴에서 켬).

## 캐릭터 외형 (의상실 그림)

의상실 그림 묶음(`oldbaram_avatar_sprites`)을 빌드에 넘기면 캐릭터를 장비로 입힙니다.
`tools/avatar_assets.py`가 각 그림에서 기본 캐릭터(머리 0, 남자기본)와 다른 부분만 떼어 머리·무기·방패
층을 만들고, 그림마다 다르게 찍힌 걷기 프레임 순서를 기본 캐릭터 기준으로 맞춥니다. 의상실 그림은
몬스터 그림보다 크게 그려져 있어 원작 화면 비율(캐릭터 ≈ 처녀귀신 키)에 맞게 0.64배로 줄입니다.
4방향 × (서기, 공격, 마법, 앉기, 걷기 4프레임)을 씁니다. 직업마다 입는 장비 줄(`web/js/avatar.js`의
`GEAR`)이 있고, 우두머리·보스의 보물 상자에서 다음 장비가 나오며 찾은 장비는 다음 사냥에도 남습니다.

## 빌드

```sh
sdkmanager "platforms;android-35" "build-tools;35.0.0"
ANDROID_HOME=/path/to/sdk ./build.sh /path/to/oldbaram_images [오디오 폴더] [의상실 그림 폴더]
```

`oldbaram_images`는 이미지 zip을 푼 폴더입니다(`image/`, `magics/`, `itemImage/`, `maps/`,
`_pages.json`이 들어 있는 곳). 서명 키는 `keystore/`에 만들어지며, 같은 키로 서명해야 기록을
유지한 채 업데이트 설치가 됩니다.

브라우저로 해 보려면 `build/assets/www`를 아무 정적 서버로 열면 됩니다.
`?all`을 붙이면 모든 사냥터가 열리고, `?speed=4`를 붙이면 4배속이 됩니다.

## 효과음·배경음 넣기

원작 소리 파일은 번호가 붙은 wav(`001.wav`…)와 MIDI 음악입니다. `audio/sfx/`에 wav를, `audio/bgm/`에
mid를 넣고, 번호별 이름 목록이 있으면 `audio/names.json`(`{"014": "건곤대나이", …}`)으로 둡니다.
빌드할 때 wav는 OGG로, MIDI는 fluidsynth와 GM 사운드폰트(`apt-get install fluidsynth fluid-soundfont-gm`)로
OGG로 바꿉니다. 마법과 게임 소리는 `web/js/game.js`의 `GAME_SOUNDS`에 원작 번호로 연결되어 있습니다
(커뮤니티 정리 "마법소리번호"와 영문판 커뮤니티 서버 RTK-Server의 사용처 기준. 예: 건곤대나이 014,
화염주 계열 040~044를 단계별로, 레벨업 123). 게임 안 **메뉴 → 소리 맞추기**에서 바꿀 수 있습니다.

- **빠르게 나누기**: 아직 나누지 않은 소리를 하나씩 들려주고, 종류 버튼(회복, 불, 얼음·물, 번개,
  베기·타격, 폭발·큰 마법, 빛·신비, 몬스터, 알림, 모름·안 씀)을 한 번 누르면 다음 소리로 넘어갑니다.
  각 마법과 게임 소리는 자기 종류로 나뉜 소리 중에서 자동으로 골라 씁니다(화염주는 '불', 뇌진주는
  '번개'…). 003~010은 기원 8단계 회복음으로 미리 나눠 두었고, 기원은 단계마다 다음 번호를 씁니다.
- 항목별 ◀ ▶: 특정 소리만 번호를 직접 바꿀 때 씁니다.

### 직접 이름 붙인 파일


`audio/bgm/`, `audio/sfx/`에 파일(ogg, mp3, m4a, wav)을 넣고 다시 빌드합니다. 이 폴더의 파일은
git에 올라가지 않습니다. 파일이 없는 마법은 소리를 내지 않습니다(가짜 소리로 원작 느낌을 해치지 않도록). 레벨업·피격 같은
기본 소리만 파일이 없을 때 간단한 소리로 대신합니다.

- 배경음(`audio/bgm/`): `title`(처음 화면), `battle`(사냥), `boss`(보스). 예: `battle.mp3`.
  이름이 다르면 title·boss가 아닌 첫 파일을 사냥 음악으로 씁니다.
- 효과음(`audio/sfx/`): 가장 구체적인 이름부터 찾습니다.
  - 기술: `skill_<기술 id>` → `skill_<종류>` → `skill`. 예: `skill_w_ult.ogg`(건곤대나이),
    `skill_m_fire.ogg`(화염주), `skill_strike.ogg`(떨어뜨리는 기술 전부)
  - 그 밖: `hit`, `kill`, `hurt`, `pickup`, `levelup`, `boss`, `chest`, `heal`, `win`, `lose`

기술 id는 `web/js/data.js`의 `SKILLS`에 있습니다.

## 배경음

MIDI 12곡을 악기와 빠르기로 나눠 붙였습니다(곡 이름이 없어 추정입니다). 처음 화면은 국악기(가야금,
거문고, 대금, 아쟁, 꽹과리)로 편성된 유일한 곡인 8번, 보스는 가장 빠르고 북이 들어간 4번,
흉가는 월광 소나타(1번), 일본은 샤쿠하치·고토의 Sawi(10번), 바닷속은 망강남(12번), 산적굴은
이천영월(9번)입니다. 나머지는 `web/js/data.js`의 각 사냥터 `bgm`에 있고, 게임 안 소리 맞추기에서 바꿀
수 있습니다.

## 업데이트 설치

빌드할 때마다 버전 코드가 올라가고 처음 화면 아래에 빌드 시각이 나옵니다. 앱은 내장 파일을 캐시하지
않으므로, 새 APK를 설치하면 바로 새 버전이 뜹니다. 같은 서명 키(`keystore/`)로 빌드해야 기록을
유지한 채 덮어 설치됩니다.
